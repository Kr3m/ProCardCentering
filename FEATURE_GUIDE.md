# Clickable Card Enlargement Feature

## Overview
The Pro Card Centering Tool now features clickable cards that allow you to enlarge and fine-tune card positioning in a dedicated modal view.

## How to Use

### Opening the Enlarged View
1. Load a front or back card image using the "Load Front Image" or "Load Back Image" buttons
2. **Click on the card image** to open the enlarged modal view
3. The card will appear at maximum size with all centering guides visible

### Adjusting Guides in Enlarged View
1. **Drag guides** to adjust the card positioning:
   - **Red guides**: Outer card borders
   - **Blue guides**: Inner image/print borders
2. Position guides precisely for accurate centering calculations
3. The guides constrain to the card boundaries during dragging

### Saving Changes
- **Save Changes**: Click the "Save Changes" button to apply your adjustments to the main view
- **Cancel**: Click "Cancel" or the X button to discard changes without saving
- **Close via overlay**: Click the dark overlay to close without saving

## Features

✅ **Enlarged View**: See the card at the largest supported size for precise adjustments
✅ **All Guides Available**: Access all 8 centering guides (4 outer + 4 inner) in the enlarged view
✅ **Smooth Dragging**: Guides snap to precise positions as you drag
✅ **Position Persistence**: Your adjusted positions are saved to the main view when you save
✅ **Non-destructive**: Canceling discards changes; your main view remains unchanged

## Tips

- Use the left-click drag interaction to move guides smoothly
- Guides constrain to card boundaries - you cannot drag outside the card
- The enlarged view maintains the card's aspect ratio for accurate sizing
- Adjustments in the modal are separate from the main view until you click "Save Changes"
- You can open and close the modal multiple times to fine-tune positioning

## Integration with Existing Features

The clickable card feature integrates seamlessly with existing features:
- **Auto-detect Borders**: Still available in the main view
- **Toggle Grid**: Grid toggle applies to both main view and modal
- **Reset Guides**: Reset button in main view affects all guides
- **Centering Calculations**: Updated in real-time as you save changes from the modal
